## Przykłady dla zrozumienia tablic

## 1. Dane a reguły

- Tablica ma jeden typ elementów i stałą długość. Jej zawartość można zmieniać, długości istniejącej tablicy nie.
- Numer pokoju jest częścią reguł gry (1–4); indeks jest pozycją w tablicy (0–3). Najpierw sprawdź numer, dopiero potem oblicz indeks.
- `Length` jest liczbą elementów, nie ostatnim indeksem. Warunek pętli indeksowej używa `< Length`.
- `new bool[4]` tworzy cztery false. Samo utworzenie tablicy nie oznacza odwiedzenia recepcji.
- Tablice nazw i odwiedzin mają odpowiadające sobie elementy. To świadomy etap przed obiektem z C3, nie docelowy model rozbudowanego świata.

### Listing C2-A

- Menu lodziarni pokazuje różnicę numeru widocznego dla człowieka i indeksu tablicy. Gra nadal wymaga własnej implementacji nazw i odkryć.
- Kompletny osobny program konsolowy; zastępuje `Program.cs` w projekcie prób poza folderem gry. Nie wklejaj wszystkich przykładów do jednego pliku.

```csharp
string[] smaki = { "wanilia", "kakao", "mango" };
int numerZMenu = 2;
if (numerZMenu >= 1 && numerZMenu <= smaki.Length)
{
    int indeks = numerZMenu - 1;
    Console.WriteLine(smaki[indeks]);
}
else
{
    Console.WriteLine("Nieznany numer");
}
for (int i = 0; i < smaki.Length; i = i + 1)
{
    Console.WriteLine((i + 1) + ": " + smaki[i]);
}
```

Oczekiwany wynik:

```text
kakao
1: wanilia
2: kakao
3: mango
```
- Przewidź i zmień:
    - numerZMenu równy 0, 3 i 4
    - dla 0/4 oczekuj odmowy przed odczytem
    - dla 3 mango
    - pętla nadal wypisuje wszystkie trzy elementy.

## 2. Funkcja odczytująca tablicę

- Parametr pozwala sprawdzić funkcję na danych niezależnych od gry.
- `foreach` daje kolejne wartości
    - gdy potrzebujesz także numeru pozycji albo zmieniasz konkretny element - wybierz `for`
- Nie używaj `pokoj` jako licznika pętli
    - sam odczyt nie może przestawiać gracza

### Listing C2-B

- Suma liczb ilustruje akumulator i wynik funkcji. W grze trzeba samodzielnie ustalić, kiedy zwiększyć licznik wartości true.
- Kompletny osobny program konsolowy; zastępuje `Program.cs` w projekcie prób poza folderem gry. Nie wklejaj wszystkich przykładów do jednego pliku.

```csharp
int[] temperatury = { -3, 4, 0 };
Console.WriteLine(Suma(temperatury));
Console.WriteLine(Suma(new int[0]));
int Suma(int[] dane)
{
    int wynik = 0;
    foreach (int wartosc in dane)
    {
        wynik = wynik + wartosc;
    }
    return wynik;
}
```

Oczekiwany wynik:

```text
1
0
```
## 3. Tablica jako argument nie jest automatycznie kopiowana

- Jeśli funkcja zmieni element przekazanej tablicy, zmiana będzie widoczna u wywołującego. Dlatego funkcja zliczająca ma tylko czytać.
- Reset odkryć jest zmianą celową: wyczyść wszystkie elementy pętlą, potem oznacz pokój początkowy.

### Listing C2-C

- Przykład pokazuje celową zmianę tablicy przekazanej do funkcji; nie jest implementacją resetu ani ruchu gry.
- Kompletny osobny program konsolowy; zastępuje `Program.cs` w projekcie prób poza folderem gry. Nie wklejaj wszystkich przykładów do jednego pliku.

```csharp
bool[] pola = new bool[2];
Console.WriteLine(pola[0]);
ZaznaczPierwsze(pola);
Console.WriteLine(pola[0]);
void ZaznaczPierwsze(bool[] dane)
{
    if (dane.Length == 0) return;
    dane[0] = true;
}
```

Oczekiwany wynik:

```text
False
True
```
## 4. Punkty integracji

- Przed Start(): tablice z kontraktu.
- Start(): reset odkryć przed pierwszym pokazaniem opisu.
- Idz(): dopiero po wszystkich odmowach i przypisaniu poprawnej pozycji zaznacz odwiedziny; nie dopisuj nowego kosztu.
- Mapa(): odczyt pozycji i tablic; osobne oznaczenia „bieżący” i „odkryty”.
- PokazOdkrycia(): pętla po danych; korzystanie z NazwaPokoju; jedno zliczenie.
- Rozdzielacz i Pomoc(): nowa komenda bez drugiej pętli ReadLine i bez nowego resetu.

## Kontrakt techniczny

| Element | Umowa |
|---|---|
| `string[] nazwyPokojow` | Dokładnie 4 niepuste nazwy wyświetlane. Kolejność odpowiada pokojom 1–4. Nie zmieniamy tablicy podczas rozgrywki. |
| `bool[] odwiedzone` | Długość 4; element o indeksie 0 odpowiada pokojowi 1. Po starcie true tylko w pierwszym elemencie. |
| `NazwaPokoju(int numer)` | Zachowuje dotychczasową sygnaturę; czyta nazwę z tablicy. Dla numeru spoza 1–4 zwraca Nieznane pomieszczenie. |
| `int PoliczOdwiedzone(bool[] dane)` | Liczy true przez pętlę; nie modyfikuje argumentu; dla pustej tablicy zwraca 0. W tym ćwiczeniu wywołujący przekazuje istniejącą tablicę, nie null. |
| `void PokazOdkrycia()` | Wyświetla numery i nazwy wyłącznie odwiedzonych pokojów oraz liczbę x/4. Bez zmian stanu. |
| `odkrycia` | Nowa komenda rozdzielacza; uruchamia PokazOdkrycia, także po końcu gry. |
| `Mapa()` | Nadal 4 wiersze; osobny znacznik aktualnej pozycji i osobne oznaczenie odkryty/nieodkryty. Pełne nazwy pozostają widoczne; nie robimy mgły wojny. |
| `Start()` | Czyści odkrycia pętlą, następnie oznacza pokój startowy. Nie zmienia nazw. |
| `Idz()` | Po zatwierdzeniu pozycji oznacza ją jako odwiedzoną, przed wyświetleniem opisu. Nie robi tego przy odmowie i nie nalicza dodatkowej energii. |
